A MERN stack Gemini AI Powered Resume Checker application.

<img src="screenshot.png" />
</p>

### Installation

```bash
git clone git@github.com:MehulBawadia/mern-talentra.git

# For Backend
cd mern-talentra/backend
cp .env.example .env
npm install
npm run dev

# For Frontend
cd mern-talentra/frontend
npm install
npm run dev
```
